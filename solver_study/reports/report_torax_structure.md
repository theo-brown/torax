# TORAX residual/Jacobian structure map (subagent report, read-only analysis of torax/_src)

## 1. Transport smoothing: kernel, cutoff, half-width, and how it is applied

**Kernel** (`transport_model/transport_model.py:343-346`):
```
r_diff = rho_face_norm[:,None] - rho_face_norm
kernel = exp(-ln2 * r_diff**2 / (sigma**2 + eps))      # = 2^{-(drho/sigma)^2}, Gaussian with HWHM = sigma = smoothing_width
```
sigma is a per-row (destination face) profile: `smoothing_width` everywhere (`:308-317`) or per `smoothing_zones` (`:298-306`), zeroed for rho >= rho_norm_ped_top when pedestal mode is INTERNAL_BOUNDARY_CONDITION and set_pedestal (`:319-340`). Rows/columns with sigma <= 1e-5 are masked (`:350-359`), zero rows restored to identity (`:362-365`). Then: row-normalise (`:368-369`) -> zero entries of the normalised kernel below `lower_cutoff = 0.01` (`:289`, `:372`) -> row-normalise again (`:375-376`). The cutoff is applied to the row-normalised weight, so the truncation radius depends on each row's sum: rows at the axis/edge (or adjacent to a zeroed pedestal zone) are one-sided with roughly half the sum and reach further.

**Arithmetic** (uniform face grid, D = 1/n_rho, w(k) = 2^{-(kD/sigma)^2}, sigma = 0.1; verified with a numpy replica):
- n_rho = 50: interior row sum ~10.645; cutoff <=> w(k) > 0.1065 <=> k <= 8 -> interior half-width 8 faces (k = 9 is 0.6% below the cutoff); one-sided boundary rows: h = 10; rows 1-10 from either boundary: 9.
- n_rho = 100: interior h = 14; boundary rows 17; rows 0-2: 17, 3-6: 16, then 15, mid 14.

**Mapping to cell Jacobian bandwidth.** Cell i's T/n residual uses d_face/v_face at faces i, i+1; smoothed chi at face f = sum_j K[f,j] chi_raw[j] over |j-f| <= h; chi_raw at face j depends on T/n at cells j-1, j and on psi at cells j-2..j+1 (via `calc_s_rmid`). Hence T/n columns reach h+1 cells and psi columns h+2 cells: 9-11 cells at n_rho = 50, 15-18 at n_rho = 100 (the measured 11-12 / ~23 is one-two cells more; the k = 9 weight sits 0.6% below the cutoff, so the reach is extremely sensitive to the cutoff). Colouring estimate: (2b+1)C colours for half-bandwidth b and C = 4 channels -> 76-92 at n_rho = 50, 124-148 at n_rho = 100, vs 12-14 unsmoothed (14 rather than 12 because the psi-column half-bandwidth is 2).

**Application**: `_smooth_coeffs` (`transport_model.py:241-265`) does a dense `jnp.dot(smoothing_matrix, coeff)` for each of chi_face_ion, chi_face_el, d_face_el, v_face_el via `jax.tree.map`, wrapped in `jax.lax.cond(jnp.all(coeff == 0.0), identity, matmul)`. Under `jax.jacfwd` the predicate depends only on primals, so the cond survives and the JVP follows the branch taken; chi is clipped to chi_min > 0 before smoothing, so the cond has no effect on Jacobian sparsity. Smoothing is applied after clipping (`:100-112`), so clipping kinks are spread across the kernel width. psi is never smoothed (`fvm/calc_coeffs.py:333-334`).

## 2. Locality of everything else in the residual path

- `CellVariable.face_value()` (`fvm/cell_variable.py:343-353`): inner face j = linear interpolation of cells j-1, j. `face_grad()` (`:224-299`, `:73-115`): 3-point stencil that reduces to 2-point (cells j-1, j) on a uniform grid; `grad()` (`:355-358`) -> cells i-1, i, i+1.
- `calc_q_face` (`physics/psi_calculations.py:108-124`): psi cells j-1, j. `calc_s_face` (`:192-215`) and `calc_s_rmid` (`:218-250`, used by QLKNN): `jnp.gradient` over faces j-1, j+1 -> psi cells j-2..j+1 (T/n rows have half-bandwidth 2 in the psi columns even without smoothing; psi rows stay tridiagonal).
- QLKNN inputs (`qualikiz_based_transport_model.py:173-290`): normalised gradients from face_grad/face_value, q_face, smag = calc_s_rmid, Ti_Te, LogNuStar (local), normni, alpha - all local. Batched once over all faces (`qlknn_transport_model.py:325-336`).
- `calc_coeffs._calc_coeffs_full` (`fvm/calc_coeffs.py:217-566`): Sauter conductivity (local), `build_source_profiles(explicit=False)` (`:240-249`), transient coefficients local; `jnp.gradient` at `:423-430`, `:453` multiplied by Phi_b_dot (zero for static geometry); psi.grad() at `:473`.
- Bootstrap current (`neoclassical/bootstrap_current/sauter.py:89-140`): face values/gradients - local; computed inside every residual (`sources/source_profile_builders.py:95-99`).
- `update_core_profiles_during_step` (`core_profiles/updaters.py:55-130`): `get_updated_ions` (`getters.py:593-767`, local: Mavrin charge states, Z_eff algebra, `jnp.where` guards) -> q_face, s_face -> `_update_energy_state` when `prev_core_profiles` is given (`:113-121`). The residual passes `prev_core_profiles=core_profiles_t, dt=dt` (`fvm/residual_and_loss.py:370-378`), so `_update_energy_state` (`updaters.py:359-404`) -> `math_utils.volume_integration` is evaluated in every residual: a global scalar depending on all T_i, T_e, n_e cells. It only feeds back through pedestal models reading `internal_plasma_energy.dW_thermal_dt_smoothed` (`pedestal_model/formation/power_scaling_formation_model.py:75, 107`), evaluated implicitly only if `pedestal.explicit_pedestal=False` or mode ADAPTIVE_TRANSPORT (`calc_coeffs.py:283-316`; default explicit). Otherwise XLA dead-code-eliminates it.
- Other global normalisations that depend on the evolving state inside the residual, if configured: `sources/cyclotron_radiation_heat_sink.py:100-112, 344-346` (least-squares fit of the T_e shape, volume rescaling) -> dense T_e coupling; `impurity_radiation_constant_fraction.py:60-78` (volume integral of all other heating sources); `ion_cyclotron_source/scaled_profile.py:117-121`, `toric_nn.py:457`; pedestal P_SOL (`power_scaling_formation_model.py:65-75`). Not state dependent: `sources/formulas.py:52,84`, `generic_current_source.py:77`. Ohmic (`sources/ohmic_heat_source.py:60-83`) recomputes `calc_j_total` and `calculate_psidot_from_psi_sources` (`psi_calculations.py:398-450`, tridiagonal operator on psi, local) -> T_e rows get a bandwidth-2 psi coupling, nothing global.
- Not in the residual: the nbar normalisation (`getters.py:165-178`) is called only once per step (`updaters.py:336`). psi boundary condition (Ip or v_loop) is fixed before the solve (`updaters.py:302-357`, `psi_calculations.py:338-362`); inside the residual `vec_to_cell_variable_tuple` re-attaches the fixed constraints.
- Implicit vs explicit sources: `sources/base.py:53` `is_explicit = False` for every source and every source's `mode` defaults to MODEL_BASED; `build_source_profiles(explicit=False)` recomputes qei, bootstrap and every source on every residual/Jacobian evaluation. Only `ei_exchange` is present by default (`sources/pydantic_model.py:51`).

FVM assembly: `fvm/convection_terms.py:70-73` sign * `jnp.maximum(eps,|d_face|)`; `:93-113` Peclet power-law with 5 `jnp.where` branches (state dependent for n_e when V_e != 0). `residual_and_loss.py:144-153` `error_if` is an identity pass-through. Core-profile updates/physics: `physics/charge_states.py:159` `jnp.clip(T_e, *T_e_allowed_range)` (Mavrin fit range -> dZ/dT_e = 0 outside); `getters.py:312-321, 491-492, 685-710` where guards; `psi_calculations.py:114-120, 199-204, 236-241` |.| in q and s; `ohmic_heat_source.py:83` `jnp.abs(j_total*psidot)`. No explicit temperature floor besides the charge-state clip; negative T produces NaN which the line search rejects (`solver/jax_root_finding.py:261`).

## 4. Residual scaling and convergence norm

The theta-method equation is multiplied by dt/tc_in_new (`residual_and_loss.py:83-101`), so the residual has the units of the solver state x: R = x_new - (tc_in_old/tc_in_new) x_old - scale_new (C_new x_new + c_new), `scale_new = dt theta/(tc_out_new tc_in_new)` (`:155`). Solver units: `convertors.STATE_SCALING_FACTORS` = {T_i: 1 (keV), T_e: 1 (keV), n_e: 1e20 (m^-3), psi: 1 (Wb)} (`core_profiles/convertors.py:42-49`). Convergence and line search both use `_mean_abs_norm = jnp.mean(|R|)` over all cells x channels (`jax_root_finding.py:33-35`), tol `residual_tol = 1e-5`, `residual_coarse_tol = 1e-2`, `tau_min = 0.01`, `n_max_iterations = 30`. Not scale-consistent: channels are in different units, the mean over N C entries dilutes localised residuals, and psi increments per step (~V_loop dt) are typically much smaller than T increments, so the T channels dominate acceptance and convergence. A per-channel row scaling exists (`convertors.py:161-220`, `compute_residual_scaling_vector`, `RESIDUAL_SCALE_FLOORS`) but is never called; `newton_raphson_solve_block.py:242-253` does not pass `linesearch_norm`/`convergence_norm`. A `custom_jac` hook exists (`jax_root_finding.py:59, 110-111`) but is rejected when `use_jax_custom_root=True` (the default). Docs say ||R||_2 (`solver_details.rst:298-300`); code uses mean-abs.

## 5. What the docs say

- `docs/solver_details.rst:209-210`: linear solver = fixed-point iteration ("predictor-corrector"). `:255-263`: Pereverzev-Corrigan "stabilize[s] the solution, at the cost of accuracy over short transient phenomena, demanding care in the choice of dt and the value of the artificial diffusion term." `:291-297`: J by autodiff, solved with LU. `:302-322`: robustness via line search plus dt backtracking. `:339-369`: fixed dt vs adaptive dt with dt_base = drho_min^2/(2 chi_max), "c_mult can be significantly larger than unity for implicit solution methods"; defaults chi_timestep_prefactor = 50, fixed_dt = 0.1 (`configuration.rst:542-546`).
- `docs/configuration.rst:2587-2591, 2642-2645`: use_pereverzev "critical for stable calculation of stiff transport"; warm-start Newton with the predictor-corrector and several corrector steps. `:2600-2612`: THOMAS vs DENSE applies to the linear solver only; the Newton path never exploits sparsity. `:1504-1508`: smoothing_width default 0.0 with a warning recommending non-zero smoothing for QLKNN. `:948-956`: explicit_pedestal default True.
- `docs/fvm.rst:33-40`: Newton-Raphson differentiates through the diffusion coefficients. `docs/roadmap.rst`: no solver work listed. Code TODOs: `transport_coefficients_builder.py:106-109` (Pereverzev pattern slows compilation ~10%), `residual_and_loss.py:410`, `jax_root_finding.py:84-86` (custom_root and compile time).

## 6. QLKNN_7_11 architecture (fusion_surrogates)

`qlknn_7_11_v1`: a single fully-connected MLP, 10 inputs [Ati, Ate, Ane, Ani, q, smag, x, Ti_Te, LogNuStar, normni] -> 5 hidden Dense layers of width 133 with tanh -> Dense(8) outputs [itgleading, itgqediv, temleading, temqidiv, tempfediv, etgleading, itgpfediv, gamma_max]; 73,823 parameters (~148 kFLOP + 665 tanh per face). Fluxes from targets (`qlknn/qlknn_model.py:298-323`) use `clip(leading, 0)`. At n_rho = 50 (51 faces) one residual costs ~7.5 MFLOP of NN work; a dense jacfwd with 200 tangents pushes ~200 JVPs through it (~3 GFLOP) versus 14 (unsmoothed) or ~76-92 (smoothed) colours.
